AI Rule

1. Debounce & Anti-Flooding

One row = one real incident, never one frame. Smoking = 3 consecutive frames; fight ≥ 1.5 s.

Metrics

2. Dual Timestamps

timestamp (capture) vs received_at (DB write) measures pipeline latency.

Safety

3. Strict Validation

Unknown fields rejected (extra="forbid"). Typos fail with HTTP 422, never silent drop.

Defaults

4. Defaults (Q1–Q5)

Store confidence ≥ 0.5; 10 s pre + 5 s post clip; 30-day clip / 12-month alert retention.
